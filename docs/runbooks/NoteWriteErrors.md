# NoteWriteErrors

За последнюю минуту были ошибки записи; условие сохраняется 2 минуты.
Единичная ошибка видна на дашборде, но не вызывает этот алерт.

1. Откройте Grafana → Сервис → «Запись заметок — бизнес-ошибки».
2. Проверьте возможность INSERT, права на `notes` и sequence, режим read-only,
   свободное место и логи PostgreSQL. `health.php` проверяет только `SELECT 1`.
3. Проверьте DEMO_USER_ID и существование владельца в users, ограничения title и внешние ключи. Если шёл учебный тест, остановите ошибочные POST.
4. Повторите POST: `success` должен расти, `error` — перестать расти.
   После выхода ошибок из окна 1m алерт погаснет.

При отсутствии POST этот алерт не проверяет возможность записи заранее.
Для этого нужна отдельная синтетическая проба записи с очисткой тестовых данных.
