# Изменения метрик и их описаний

Основа — предыдущая работа local_zoo_for_vyatgu, ветка feat/note-write-monitoring.
В trello-web до переноса не было Prometheus, экспортера приложения и дашбордов.

| Объект | Было / обнаружено | Стало |
|---|---|---|
| Результат записи | HTTP 302 и при успехе, и при исключении INSERT | app_note_write_operations_total с outcome=success/error считает реальный исход ORM-сохранения; редирект сохранён |
| Описание попытки | «Completed note writes by outcome» без границ измерения | Завершённая валидная попытка: исключения подключения и INSERT — error, HTTP 422 исключён; один исход в finally |
| Время записи | В предыдущем стенде подключение и INSERT через PDO | Ленивое подключение, Eloquent и INSERT. Секунды, монотонные часы. Без валидации, рендеринга и очереди FPM |
| Созданные заметки | «Количество созданных записей» | Успешные INSERT с момента рестарта FPM; counter, не размер таблицы и не количество всех POST |
| Начальное состояние | Серии до первого события могли отсутствовать | success, error, notes_created экспортируются с нуля; гистограмма появляется после наблюдений |
| HTTP-ошибки | 5xx можно ошибочно принять за все сбои | В описании явно сказано: 5xx не замечает ошибочный INSERT с 302; отдельная бизнес-доля ошибок |
| Error ratio по route | Числитель по route делился на общий трафик | Делится на трафик того же route; это доля ошибок маршрута |
| Кардинальность | Путь PHP-скрипта | Явный список /index.php, /health.php, other. URL, ID, title/content и исключения не используются в labels |
| Доля ошибок записи | Пустую панель можно принять за 0% | При отсутствии попыток доля не определена; значение не заменяется нулём |
| Ошибки за 5 минут | Можно принять за точный целочисленный журнал | Указана экстраполяция increase и возможность дробного результата |
| p95 записи | Кратко «подключение и INSERT» | Приблизительный квантиль по бакетам, отдельно по исходу, секунды; без наблюдений не определён |
| Успехи за период | or vector(0) скрывал отсутствие серии | Резервный ноль убран: отсутствие данных не выдаётся за отсутствие созданий |
| SQL latency | К queryid присоединялся текст SQL | SQL-текст не экспортируется; топ среднего времени по queryid. Среднее явно отделено от p95 |
| up, pg_up, probe_success | Зелёное состояние можно принять за полную исправность | Разделены scrape, соединение экспортера с БД и конкретная HTTP-проба; ни один не доказывает возможность INSERT |
| NoteWriteErrors | Правило предыдущего стенда | Сохранено: ошибки в окне 1m, условие непрерывно 2m, warning. Одна ошибка видна на графике, но не обязана вызвать уведомление |

## Изменения проекта

1. Overlay переключает CLI на FPM и добавляет nginx: появляются настоящий пул
   воркеров, общая память APCu и инфраструктурные метрики. Базовый режим сохранён.
2. Перенесены экспортеры, scrape targets, provisioning Grafana, правила и runbooks;
   имена сервисов адаптированы к app/db, порты UI не конфликтуют с предыдущим стендом.
3. Добавлен health с SELECT 1; metrics закрыт на пользовательском порту nginx.
4. Исправлены блокеры проверки: порядок users → notes в runner без переименования
   миграций, note_id/created_datetime вместо id/created_at, обязательный user_id
   в INSERT. Добавлен явный демопользователь, а не вымышленная авторизация.
5. README теперь описывает текущий код и отдельно обозначает будущие функции досок.

## Ограничения

Без POST счётчик не проверяет возможность записи заранее: нужна отдельная синтетическая
проба записи с очисткой. Рестарт APCu сбрасывает counters; события между последним
scrape и рестартом могут потеряться. PHP latency не включает очередь FPM; внешняя
проба измеряет свой полный HTTP-запрос. Пороги алертов учебные.

Имена прикладных метрик сохранены для совместимости с предыдущей работой.
Уточнения внесены в HELP метрик, комментарии, описания панелей и
[каталог метрик](METRICS.md).
